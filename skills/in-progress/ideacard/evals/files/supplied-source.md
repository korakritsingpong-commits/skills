# ข้อกำหนดการ์ดคำถามฉบับทดสอบ
ผู้สร้าง: ผู้ใช้สมมติสำหรับการทดสอบ
เวอร์ชัน: 1.0

## การ์ดก่อนค้น
การ์ดก่อนค้นต้องมีรหัสคงที่ คำถามหลัก และขอบเขตที่ชัดเจน
ให้เว้นคำตอบสรุปเป็นข้อความว่าง และให้ข้อกล่าวอ้างกับแหล่งข้อมูลเป็นรายการว่าง
สถานะของการ์ดเป็นร่าง และวันที่ตรวจสอบเป็น null

## หลังค้น
เติมคำตอบและข้อกล่าวอ้างพร้อมหลักฐานลงการ์ดรหัสเดิม
สร้างคำถามพื้นฐานต่อยอดเป็นการ์ดร่างแยกใบ
